A modular container app housing multiple mini-projects practiscing on Swift.
The project list: 
1. Cute Calculator: A basic calculator application using UIkit, MVC, and managing operation flow.
2. My Favorite Place: UICollectionView using UICollectionViewCompositionalLayout, UICollectionViewDiffableDataSource and NSDiffableDataSourceSnapshot.
3. Food App: UICollectionView using UICollectionViewFlowLayout and JSON data loading.
4. Focus Plant *(In Development)*: A focus timer app using Timer, UIView transition animations, UIAlertController, CAShapeLayer, UIPanGestureRecognizer, and AVAudioPlayer.
